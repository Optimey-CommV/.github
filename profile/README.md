# Optimey

Optimey is de zaak van [Joost Meyfroodt](https://github.com/optimey), freelance systeem- en securityarchitect in Deinze. Ik ontwerp, bouw en beveilig IT-infrastructuur: netwerken, virtualisatie, containers en de back-ups waarmee je terug op de been bent als het toch misloopt.

## Waarmee ik help

- Architectuur- en securityreviews van bestaande omgevingen, met een eerlijk verslag van wat zwak is en wat eerst moet
- Virtualisatie en containers op Proxmox VE, LXC en Docker
- Netwerken en netwerkbeveiliging, onder meer met Ubiquiti
- Versleutelde, geautomatiseerde back-ups die je ook effectief kan terugzetten
- Automatisatie op Linux met Python en shell

## Wat hier staat

Tools die ik schrijf buiten klantenopdrachten om. Je mag ze gebruiken, aanpassen en verder verspreiden onder de [GNU GPL, versie 3 of later](https://www.gnu.org/licenses/gpl-3.0.html). Klantencode staat hier niet en komt hier ook niet.
